3. Accessibility & Best Practices
rel="noopener noreferrer" on External Links

Always include rel="noopener noreferrer" whenever target="_blank" is used to prevent potential security issues and improve performance.

aria-label for Icons

If you use an icon (e.g., envelope icon) instead of text for “Send Email,” add aria-label="Send email to info@venator-capital.net" so screen readers can announce it.

Focus States

Ensure that both “Send Email” and “Open Contact Form” links/buttons show a visible focus outline for keyboard navigation:

css
コピーする
編集する
:focus {
  outline: 2px solid #FFD600;
  outline-offset: 2px;
}
In Tailwind, you can use focus:outline-none focus:ring-2 focus:ring-[#FFD600] classes on <a> or <button>.

Consistent Styling

Use the same Tailwind utility classes for all buttons/links to maintain consistent hover, active, and focus styles throughout the site.

4. Testing & Verification
Manual Verification (Before Deploying)

Click each “Send Email” link/button:

A new email compose window should open with “To:” set to info@venator-capital.net.

Click each “Open Contact Form” link/button:

A new browser tab should open to https://forms.gle/iBogvoWnzHyXYQ2X8.

Verify on both desktop and mobile viewports that clicking behaves correctly (e.g., does not try to navigate within the SPA).

Test keyboard navigation: Tab through to the links/buttons and confirm you see a focus outline.

Cross-Browser Testing

Chrome, Firefox, Safari (macOS), Edge: ensure both links function identically.

Safari on iOS / Chrome on Android: confirm “Send Email” opens the mail app, and “Open Contact Form” opens the Google Form in the device browser.

Accessibility Check

Use a screen reader (VoiceOver on macOS/iOS or NVDA on Windows) to confirm the link labels (“Send Email,” “Open Contact Form”) are read aloud properly.

Ensure contrast ratio of button text vs. background is ≥ 4.5:1.

Lighthouse or Axe Review

Run an accessibility audit in Chrome DevTools (Audit → Accessibility) to catch any missing aria- attributes or focus issues.

Run a performance/SEO audit to ensure no new issues were introduced.
